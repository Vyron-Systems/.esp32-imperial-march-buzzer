# esp32-imperial-march

Plays the Imperial March (Star Wars) on an ESP32-S3 using a buzzer on Pin 4.

## Hardware
- ESP32-S3
- Buzzer/Speaker on Pin 4 (via 100–330Ω resistor recommended)
- GND on GND

## Usage
Flash with Arduino IDE or PlatformIO.

## Disclaimer
Use at your own risk. The author is not responsible for any damage 
to hardware or components. A resistor between Pin 4 and the buzzer 
is recommended to protect the ESP32.
